# Java LeetCode Practice

A collection of Java solutions for 46 Easy-level LeetCode practice problems discussed in ChatGPT.

## Contents

| Section | Problems |
|---|---:|
| Section 01 – Basics | 6–10 |
| Section 02 – Strings | 11–20 |
| Section 03 – Basic Arrays | 21–35 |
| Section 04 – Additional Algorithms | 36–47 |
| Section 05 – Linked Lists and DP | 48–51 |

Each problem folder contains:
- `Solution.java` – LeetCode-compatible Java submission.
- `README.md` – problem number, concepts, and solution.

## How to use

1. Open the folder for the problem you want to practise.
2. Copy `Solution.java` into the corresponding LeetCode editor.
3. Submit using Java.
4. Try to understand and reimplement the solution without looking.

**Note:** LeetCode supplies the input and, for linked-list problems, the `ListNode` class. These files intentionally contain submission methods rather than standalone programs with `main()`.

## Topics covered

Loops, conditionals, strings, arrays, 2D arrays, two pointers, prefix sums, HashMap, HashSet, binary search, bitwise XOR, linked lists, dynamic programming, and Kadane's algorithm.

## Practice reminder

Use these solutions as study references. Make sure you can explain the approach, edge cases, and complexity before considering a problem mastered.
